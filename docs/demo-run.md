## 本次 Demo 暴露并修复的问题

第一次真实运行时，模型使用了 schema 中的英文 `name` 作为表头，而 validator 只识别中文 `label`，导致字段被误判为缺失。修复后:

- Table Validator 同时支持 `label` 和 `name` 作为表头匹配依据。
- 生成 prompt 明确要求表头优先使用中文 `label`。
- 新增单元测试覆盖 LLM 使用英文 `name` 表头的情况。

这说明质量校验模块不仅能展示结果，也能帮助发现 LLM 输出与工程约束之间的真实偏差。
